# Отдельная версия Codex

Этот репозиторий независим от разработки Claude. Сборка, игровые проверки,
скриншоты и релизы выполняются только здесь, через GitHub Actions.

## Установка на ПК

1. В настройках TLauncher задайте отдельную папку игры
   `%APPDATA%\.minecraft-codex-neoforge-1.21.1` (раскройте `%APPDATA%` в полный путь).
2. Установите в неё NeoForge 1.21.1 (21.1.265 или новее) и запустите один раз, затем закройте игру.
3. Скачайте установщик из отдельного репозитория сборки:
   https://github.com/stardely62-oss/euf-modpack-codex/releases/latest
4. Распакуйте архив и запустите `install-modpack.bat`.
5. Играйте с выбранной папкой `.minecraft-codex-neoforge-1.21.1`. Для обновления снова
   запустите этот же скрипт.

Обычная `.minecraft`, её моды, конфиги и миры не изменяются установщиком.
Скрипт откажется использовать другую папку или путь через junction/symlink.
Не копируйте основные миры для испытаний без отдельной резервной копии.
Для возврата к версии Claude верните прежнюю папку игры в лаунчере.

Для NeoForge нужен Java 21.

Моды сохраняют прежние идентификаторы для совместимости; две версии одного
мода нельзя класть в одну папку mods. Номера сборок Codex помечены `codex`.

Релизы NeoForge используют тег `neoforge-dev`, установщик — `pack-neoforge`.
Прежние dev-релизы Fabric и старый manifest сохранены отдельно.

## Уже существующий профиль test

Если NeoForge 1.21.1 установлен в `%APPDATA%\.minecraft\versions\test`,
запустите `install-test.bat`. Он ставит и обновляет моды строго в `test\mods`,
создаёт эту папку при необходимости и проверяет `test\test.json`.
Общая `.minecraft\mods` и другие профили не изменяются.
В TLauncher включите отдельную папку игры для профиля `test`: фактическая
папка игры должна быть `%APPDATA%\.minecraft\versions\test`.
Само расположение JSON версии ещё не задаёт папку игры лаунчера.
